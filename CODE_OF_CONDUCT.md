# Code of conduct

## Community expectations

People participating in this project should be treated respectfully regardless of background, identity, experience or institutional affiliation. Scientific disagreements should discuss the method, evidence and uncertainty. Criticism should help the other person understand and improve the work.

Harassment, threats, discrimination, publishing another person's private information and repeated unwanted contact are unacceptable. Do not upload identifying participant records or private information about contributors.

## Reporting and response

Report a community concern to the maintainer through GitHub private vulnerability reporting once that channel is enabled. The repository is currently a local draft and has no public reporting endpoint. A maintainer should acknowledge a report, protect confidentiality, examine the evidence and respond proportionately. Possible responses include a private reminder, a warning, removal of content, temporary participation restrictions or a permanent ban. Decisions should state the behavior being addressed and how an appeal can be made.

## Scope

These expectations apply to project issues, pull requests, discussions and events where someone represents the project. Maintainers should follow the same expectations and avoid conflicts of interest when handling reports.
